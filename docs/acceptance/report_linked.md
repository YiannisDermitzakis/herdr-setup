## § The sharp line — where drift can hide

### Not implemented — no test or surface yet

- **diff-runs-under-protocol-mismatch** — diff reports plugins, config and integration state in full even when the Herdr command line and the running server speak different protocol versions.. _Reads plugins.json and config.toml from disk; only integration state comes from the CLI, which stays unblocked._
- **socket-commands-refuse-under-mismatch** — apply, absorb, onboard and feed stop with one line naming the protocol mismatch and the restart needed, instead of parsing a JSON error object as an empty result.. _The failure this guards against reads as success having done nothing._
- **diff-detects-plugin-drift** — diff reports each manifest plugin as missing, matching its pinned ref, or moved, and lists host plugins the manifest does not name as unmanaged.. _Moved is decided by resolving the ref with git ls-remote against the commit Herdr recorded._
- **apply-reproduces-manifest** — On a host missing every manifest plugin, apply installs them at their pinned refs and a following diff reports a match.. _The second-machine case the tool exists for._
- **config-splice-preserves-plugin-blocks** — apply updates the operator's own config lines while leaving plugin-written marked blocks exactly where they were.. _A plugin owns its block; the tool must never eat it._
- **absorb-apply-roundtrip-is-noop** — absorb followed by apply against an unchanged host makes no further change, and absorb refuses to run when the manifest has uncommitted edits.. _Guards the overwrite-not-merge design against eating a hand edit._
- **onboard-offers-stale-integration** — onboard lists the agents present on the host, reports an integration Herdr calls outdated with both versions, and installs a refresh only when accepted.. _Different hosts run different agents, so this is per-host and interactive._
- **feed-reports-live-sessions** — feed reports a session id for every live agent pane and Herdr persists a record per pane; a following server restart brings each pane back running its agent's resume command rather than a bare shell.. _The end-to-end reason the tool exists. Verified live post-merge; Copilot unverified until a host with the CLI runs it._
